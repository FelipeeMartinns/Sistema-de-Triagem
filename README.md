# 🏥 Sistema de Triagem Hospitalar

Este projeto é um **sistema de triagem para hospitais**, desenvolvido para agilizar o atendimento de pacientes em unidades de saúde. O sistema organiza a fila de espera com base na gravidade do caso, melhorando o fluxo e priorização dos atendimentos.

## ⚙️ Funcionalidades

- 📝 Cadastro de pacientes na triagem
- ⚠️ Classificação de risco (por cores ou níveis de urgência)
- 📋 Lista de espera organizada por prioridade
- 🔍 Visualização e gerenciamento dos pacientes em tempo real
- 👨‍⚕️ Acesso para profissionais de saúde acompanharem o fluxo de atendimento

## 🛠️ Tecnologias utilizadas

- **Backend:** Typescript
- **Frontend:** HTML + CSS
- **Banco de dados:** MySQL
- **Outros:** Bootstrap (opcional para interface)
